# VSHPM-3-TIV
Повторить каркас сайта с дизайна фигмы

## Структура проекта

- `index.html` - основная страница со стилями
- `structure.html` - грубая структура сайта (для показа преподавателю)
- `styles.css` - стили для десктопа
- `mobile.css` - стили для мобильных устройств
- `figma.css` - исходные стили из Figma

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000 в браузере.
